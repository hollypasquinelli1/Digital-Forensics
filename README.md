# Digital-Forensics
9 digital forensics labs covering memory/disk forensics, Windows &amp; Linux artifact analysis, static malware analysis, and volatile data collection.

---

## Technical Competencies & Keywords
*   **Operating Systems:** Windows Forensics, Linux Forensics
*   **Analysis Types:** Disk & Image Analysis, Volatile Data Triage, Static Malware Analysis
*   **Core Skills:** Command Prompt/CLI Evidence Gathering, Artifact Parsing, Timeline Reconstruction
*   **Methodology:** Chain of custody preservation, cryptographic validation, non-destructive analysis

---

## Portfolio Index
Click on any lab title below to view the full PDF report and step-by-step investigation documentation directly in your browser.

### 1. Windows Command Prompt
*   **[Lab 1: Windows Command Prompt](./WindowsCommandPrompt_1.pdf)**
    *   *Focus:* Exploration of Windows command prompt and some of its commands including ping, tracert, netstat, and Sysinternals library. 

### 2. Understanding and Analysis of Image Files
*   **[Lab 2: Understanding and Analysis of Image Files](./ImageFileAnalysis_2.pdf)**
    *   *Focus:* File analysis using HxD, and hashing using different environments.
 
### 3. Disk Forensics
*   **[Lab 3: Disk Forensics](./DiskForensics_3.pdf)**
    *   *Focus:* Using Linux commands that help to conduct analysis on drives within a system. Introduction to Guymager and PowerShell cmdlets for Windows disk investigations. 

### 4. Windows Forensics Part I
*   **[Lab 4: Windows Forensics Part I](./WindowsForensicsPTI_4.pdf)**
    *   *Focus:* Exploration of Windows commands that help retrieve information from systems such as user information, privileges, and groups. Use of the commands to explore system information and volatile information. 
 
### 5. Windows Forensics Part II
*   **[Lab 5: Windows Forensics Part II](./WindowsForensicsPTII_5.pdf)**
    *   *Focus:* Using tools such as NIRSOFT, OSForensics, and Python to access browser artifacts such as cache, cookies, and history. Exploration of how to monitor and understand windows events, and handle windows registry, recycle bin, and browser artifacts with Python.

### 6. Linux Forensics - Volatile Data
*   **[Lab 6: Linux Forensics - Volatile Data](./LinuxForensicsVolatileData_6.pdf)**
    *   *Focus:* Collection of basic volatile information, the Linux firewall, SSH service, and port scanning with nmap. 
      
### 7. Linux Forensics - Linux Auditing System
*   **[Lab 7: Linux Forensics - Linux Auditing System](./LinuxForensicsLinuxAuditingSystem_7.pdf)**
    *   *Focus:* Using the Linux auditing system with auditid and security auditing using Lynis. Generation of the logs for Lynis to analyze and use for generating warnings and suggestions by use of auditid. 

### 8. Linux Forensics - Artifact Analysis
*   **[Lab 8: Linux Forensics - Artifact Analysis](./LinuxForensicsArtifactAnalysis_8.pdf)**
    *   *Focus:* Use of Linux forensics tools such as p0f, arp-scan, nmap, swap_digger, mimipenguin, rkhunter, and sleuth kit.
    
### 9. Static Malware Analysis
*   **[Lab 9: Static Malware Analysis](./StaticMalwareAnalysis_9.pdf)**
    *   *Focus:*  Using tools such as pefile, readpe, and pe-tree to extract information from malware safely without having to execute the program, and put a device at risk.
